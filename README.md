# Network Traffic Analysis & Security Lab

## About the Project

A hands-on networking and cybersecurity project focused on designing network topologies, generating network traffic, capturing packets, and analyzing network communication.

The project combines Cisco Packet Tracer and Wireshark to understand network protocols, investigate packet behavior, and develop practical network traffic analysis skills.

## Objectives

- Design and configure a functional network topology.
- Understand how devices communicate within a LAN.
- Analyze ARP requests and replies.
- Capture and inspect network traffic using Wireshark.
- Investigate ICMP communication and packet behavior.
- Understand network protocols and their security implications.

## Tools & Technologies

- Cisco Packet Tracer
- Wireshark
- IPv4 Networking
- ARP and ICMP
- Git and GitHub

## Network Topology

The current simulated network consists of:

- 1 Cisco 2811 Router
- 1 Cisco 2960-24TT Switch
- 3 PCs
- 1 Server

Network Address: 192.168.10.0/24
